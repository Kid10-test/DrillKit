Contoh cetak: kartu lipat buku saku

Ini contoh di luar aplikasi (data khayalan: show 51 set, 2 pemain). Satu lembar A4 memuat dua kartu; satu kartu = lembaran 190 × 135 mm yang dilipat dua menjadi kartu 9,5 × 13,5 cm bermuka dua. Muka depan memuat kepala kartu + kompas + set awal; muka belakang memuat sambungan set + keterangan + catatan.

  1. Tekan Cetak contoh → kertas A4 → skala 100% → matikan header/footer browser → cetak.
  2. Potong mengikuti garis tepi penuh (✂).
  3. Lipat garis putus-putus ke belakang: panel kanan menjadi muka belakang kartu.

Kalau tata letak ini disetujui, beginilah yang akan dipasang ke tombol “Buku saku” di aplikasi.
